📄 Описание ключевых файлов и их текущее состояние
1. _config.yml
Назначение: Глобальные настройки Jekyll.
Содержимое:
title: Tunless Modern
url: "https://michael-k-cloud.github.io/Tunless_Modern"
baseurl: "/Tunless_Modern"
nav_links: Главная, Инструкция, Каринг, Соглашение, Конфиденциальность.
Статус: ✅ Корректен, конфликтов нет.
2. _layouts/default.html
Назначение: Базовый HTML-шаблон, в который встраивается контент всех .md страниц через {{ content }}.
Ключевые особенности:
Глобальные CSS-переменные (--primary: #667eea, --text-light: #2d3748 и т.д.).
Переключатель темной/светлой темы с SVG-иконками (солнце/луна) и сохранением в localStorage.
ВАЖНЫЙ КОНФЛИКТНЫЙ СЕЛЕКТОР:
css
12345678
Этот селектор применяется ко ВСЕМ ссылкам внутри .content, включая кнопки .cta-button в index.md, если они не изолированы через !important или :not(.cta-button).
Логика отображения заголовка: если page.url == '/', показывает логотип + {{ page.title }} + {{ page.subtitle }}. Иначе показывает только <h1 class="page-title">{{ page.title }}</h1>.
Статус: ✅ Работает корректно, но требует учета при стилизации кнопок в index.md.
3. index.md (Главная страница)
Назначение: Лендинг с 3 карточками преимуществ и CTA-кнопками.
Текущее содержимое: Содержит встроенный <style> блок и HTML-разметку.

4. setup.md, karing.md, terms.md, privacy.md, account.md
Назначение: Контентные страницы.
Статус: ✅ Корректны. Используют title: во Front Matter, который автоматически подхватывается шаблоном default.html в виде <h1 class="page-title">. Дублирующих ## Заголовков в начале текста быть не должно.
🚨 Чек-лист для ИИ перед внесением изменений
Перед тем как предложить код для любого файла, ИИ обязан проверить:
Не ломает ли новый CSS глобальные стили в _layouts/default.html?
Используются ли !important точечно и обоснованно (только для переопределения глобальных конфликтов, таких как .content a)?
Соответствуют ли цвета (--primary, --text-light) запрошенной теме (светлая/темная)?
Не добавлены ли в код непрошеные "улучшения" или изменения структуры, о которых не просил пользователь?
Актуальны ли данные в этом файле REPOSITORY_STATE.md? (Если прошло много времени или пользователь сказал "я кое-что изменил", сначала выполнить web_extractor для целевого файла).
